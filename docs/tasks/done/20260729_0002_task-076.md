# whub/wflowのhooks整備

## Objective

Claude Code hooksからwhub/wflowを呼び、task-planning規約の遵守をプロンプト依存からハーネスによる強制へ移す

## Approach

- 検証・読み取り系コマンド(wflow check / wflow task check / whub ls)をPostToolUse・SessionStartへ載せる
- hook入力JSONを直接処理するgate subcommandを新設し、規約違反をexit 2で遮断する
- 状態遷移の自動実行は採用せず、遷移の遵守判定に限定する
