PostToolUse hookによる推定的な承認待ち解除と3秒タイムアウトを調査し、Codex App Serverを正本とする通知状態モデルと移行方針を確定する。

## Approach

- 観測事実・推論・理想像・非対象を分離し、Hook経路とApp Server経路の責務、相関キー、失敗時のUI挙動を定義する。
