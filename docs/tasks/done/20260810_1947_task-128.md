# Web Terminal の remote worktree 接続

## Objective

登録済み remote worktree の Agent tmux session を Web Terminal から SSH 経由で attach できるようにする。

## Approach

- terminal router で manifest と context から登録 worktree の remote host を解決して resolver に渡し、resolver は local/remote で既存確認と attach command を分岐する。WebSocket bridge が remote SSH attach command を起動する回帰テストを追加する。Web Agent パネルの Codex App Server の remote 実行対応は対象外。
