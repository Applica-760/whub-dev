# Todo優先度入力を色付きラジオボタンへ変更

## 目的・前提・方針案
- 目的: Todo追加フォームの優先度選択を、ドロップダウンから色付きラジオボタンへ変更して選択操作を減らす
- 前提: 優先度は既存の`none`・`red`・`yellow`・`blue`を維持し、`none`はグレーで示す
- 方針: 「優先度」ラベルを残し、選択肢はテキストなしの色付きラジオボタンとして横並びにし、Todo・Backlog・Inboxのトップ見出しはタブと重複するため除去する

## 計画

### Phase 1: 優先度入力UIの置換
- [x] `TodosPage`のpriority `Select`を色付きラジオボタンへ置換し、既存の状態・送信値・初期値を維持する
- [x] Todo・Backlog・Inboxのトップ見出しを除去し、タブをページ識別子とする

### Phase 2: 検証
- [x] `app`で`npm run typecheck`および`npm run build`を実行し、型検査とプロダクションビルドを確認する

### Phase 3: Backlogプロジェクト一覧の固定幅化
- [x] 画面幅75rem以上でプロジェクト一覧を16rem固定幅とし、メイン領域の左端へ寄せる

## 実行ログ

### 試行 1: UI変更とビルド検証
- 実施内容: Todoの優先度入力を色付きRadio.Groupへ置換し、3ページのトップ見出しを除去して`npm run typecheck`と`npm run build`を実行
- 結果: 型検査・プロダクションビルドともに成功（既存のchunk size警告のみ）
- 判断: 続行
### 試行 2: Backlogプロジェクト一覧の固定幅化
- 実施内容: 外部ディスプレイで余白列全体に広がる一覧を16rem固定幅にし、型検査とプロダクションビルドを実行
- 結果: 型検査・プロダクションビルドともに成功（既存のchunk size警告のみ）
- 判断: 続行

## 結果
- Todoの優先度を4色のラジオボタンで選択可能にし、3ページのトップ見出しを除去、Backlogのプロジェクト一覧を16rem固定幅にした
