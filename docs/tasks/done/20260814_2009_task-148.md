# ターミナルページの左ペインを見直す

## Objective

ターミナルと通知を選択できる左ペインを常時表示しやすい細さにして、ターミナル本体の表示領域を広げる。

- デスクトップの左ペインを、現在の可変幅・最小12remから固定10remへ細くする。
- WorktreeはProject名の先頭4文字とTask IDの数字部分を改行し、数字部分を薄字で表示する。
- Operator名は`term1`、`term2`のように短く表示する。
- 未確認通知は文字Badgeではなく色の点で示す。権限待ちのオレンジ枠と完了の青枠を常に確保して縦に並べ、通知の有無で再読み込みボタンを動かさない。色だけに依存しない読み上げ名も残す。
- Operator行の終了用xボタンを削除する。終了APIと既存のキーボード操作は維持する。
- OperatorとWorktreeのTerminal再読み込みボタンは残す。
- `Operations`見出し行は削除する。Operation起動は既存の`⌘⇧O`で維持する。
- Terminal選択、通知の既読化、左右ペインの折りたたみ、モバイルの1カラム表示は維持する。

## Approach

- `TerminalListPanel`とTerminalページ専用CSSを小さく変更し、共通`GroupedListRow`やbackendには影響を広げない。
- 既存のTerminalページテストを表示契約に合わせ、再読み込みとキーボードによるOperator終了を回帰確認する。

## Context

- 左ペインは`TerminalListPanel`が担当し、通知Badge、再読み込み、Operator終了を各行の右側へ横並びにしている。
- レイアウトは`terminal.css`で左列を`minmax(12rem, 0.75fr)`としており、画面幅に応じて12remより広がる。
- Operator終了は左ペインのxボタン以外に`⌘⇧X`からも実行でき、停止APIのhook単体テストもある。
- TASK-146は完了済みで、通知色と既読化の既存挙動を前提にできる。

## Plan

1. `TerminalListPanel`から見出し行、Operator終了ボタン、不要なpropを除き、再読み込みと縦2枠の通知点を固定配置する。
2. `terminalTarget`でOperator名を`termN`、Worktree名をProject先頭4文字とTask ID数字部分へ短縮する。
3. `terminal.css`でデスクトップの左列を10remに固定し、左ペイン内だけ文字、余白、改行をコンパクトにする。モバイルの1カラム規則は変えない。
4. `TerminalPage`の接続と既存テストを最小限更新し、短縮名、通知2枠、見出しとxボタンの非表示、再読み込み、`⌘⇧O`起動、`⌘⇧X`終了を確認する。
5. 集中test、typecheck、対象ファイルのformat、production buildを実行し、起動済み開発サーバのhealthを再確認する。

## Decisions

- 10remは実装前の提案値。目視確認で情報が欠ける場合だけ広げる。
- 左ペインを閉じた時にも通知を別表示する変更、幅のドラッグ調整、backend変更は対象外とする。
