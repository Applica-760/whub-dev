# whub app 統合ビュー

## 目的・前提・方針案

- `/`をwhubの一覧ビューとし、専門ページへ入る前のホームにする
- 未完了Todoと常時表示のInboxフォームを最初の要素にする
- Todo・Inboxなどの専門ページの表示・入力部品を再利用する
- Backlog要約、`whub status`、CPU・メモリ状況を後から追加できる完全ビューへ育てる
