# Terminal表示のchore修正

## Objective

Explorer幅・Agent sessionの逐次表示・Terminal縦幅を整え、端末画面を安定して使えるようにする。

## Approach

- 既存のCSS・Terminal表示・API構造を最小変更し、Project単位の失敗を他のsession表示から分離する。

## Context

- Agent session APIは全ProjectのTaskを同期的に走査し、remote worktreeではSSHによるworktree・tmux確認を行う。そのため遅延または失敗するremote Projectが一覧全体を止める。
- TerminalのExplorerは中央paneと同じ比率の1fr、xterm表示は54rem固定である。

## Plan

1. Explorer幅を縮小し、xtermの高さをviewportへ追従させる。既存ResizeObserverで行・列を再計算する。
2. Agent session APIをProject単位で取得できるようにし、UIは完了したProjectから一覧へ追加する。失敗は該当Projectだけ表示する。
3. focused test、frontend test、全体回帰を実行し、Phaseごとにcommitする。
