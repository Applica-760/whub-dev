# Web Terminalのリサイズ描画を安定化する

## Objective

画面サイズ変更時の段ずれ・ちらつきと左上の小領域だけを使う描画不整合を、サイズ同期経路の根本原因修正によって解消する

## Approach

- コンテナ・xterm・PTY/tmuxの寸法遷移を再現計測し、既存のイベント駆動fitを1フレーム単位に整理して最小修正し、回帰テストと実ブラウザで検証する

## Context

- `ResizeObserver`、`FitAddon.fit()`、PTY resize、パネル切替時の再fitは実装済み。
- 同種の症状はTASK-114・TASK-125で修正済み扱いだが、viewport追従を変更したTASK-130後も再発している。
- 常時ポーリングや無条件の強制再描画は追加せず、既存サイズ同期経路の競合・順序・重複を根本原因として調査する。

## Plan

1. 縦・横・連続リサイズとTerminal切替で症状を再現し、コンテナ、xterm行列、内部描画領域、PTY/tmuxの寸法遷移を照合する。
2. 原因箇所でresize処理を1フレーム1回へ整理し、0サイズを除外して行列変更時だけPTYへ通知する。
3. `fit()`だけで内部描画が復旧しない事実を確認した場合に限り、限定的なrenderer再描画を追加する。
4. focused test、frontend全test、typecheck、build、実ブラウザで回帰検証する。
