# 目的・前提・方針案

- 目的: 過去の開発履歴を再構成し、whubの開発ブログとして公開できる形にする。
- 前提: task、ADR、Git履歴を根拠として用い、記録欠落は照合で補う。
- 方針案: 紹介記事ではなく、時系列の開発判断と実装過程を中心に構成する。

- 配置: `slides/dev-log/`を新設（既存`slides/blog.md`は紹介ブログ草案で別物のため名前衝突を避ける）。

- 調査主体: 分量が大きいため複数Agentへ期間分割して並列委任し、結果のみ受け取って結合する。
