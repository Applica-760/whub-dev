# Terminal UIのchore修正

## Objective

Operation終了操作、Terminalレイアウト、remote worktree取得失敗時の表示を最小修正する。

## Approach

- 既存のTerminalPage・agent session取得・CSSを最小変更し、既存テストへ回帰条件を追加する。

## Context

- Operationは`⌘⇧O`で起動できるが、終了はON/OFF Switchだけである。
- Agent session取得はProject単位へ分離済みだが、remote Projectの失敗をExplorerのAlertに表示する。
- Terminalの3列とタブバーはともに`1rem`の余白・47px header/38px tabである。

## Plan

1. Operation終了を×ボタンとTerminal上限定の`⌘⇧X`へ統一する。
2. ヘッダーを40px、タブを32px、3列間隔を0.5remへ縮小する。
3. remote ProjectのAgent session取得失敗を一覧から省略し、他の失敗表示は維持する。
4. Terminal画面のExplorer・Terminal・Task系Widget見出しを非表示にして、コンテンツ領域を広げる。
5. focused frontend test、typecheck、build、`uv run pytest`で検証する。
