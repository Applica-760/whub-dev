## Objective

app/features/terminal、特にTerminalPageの責務過多を調査し、責務分離を主軸とする最小リファクタリング計画を作る

## Approach

- CodeGraphで依存関係と実行経路を確認し、ponytail fullを使うサブエージェントの独立レビューを統合する。コード削減は副次評価とし、実装は行わない

## Context

- `app/src/features/terminal/TerminalPage.tsx` は564行あり、Operator Terminalの取得・起動・停止、terminal選択・mount・reload、attention確認、shortcut、routing、Task graph/detail、一覧とterminal描画を担う。
- レビュー対象は`TerminalPage.tsx`と直接の依存・呼出元・テストに限定する。
- 親repoで作業し、実装変更は行わない。

## Plan

1. CodeGraphで`TerminalPage`の呼出元、依存先、テスト、terminal feature内の既存責務境界を確認する。
2. サブエージェントがponytail fullを使い、責務分離を主軸に独立レビューする。
3. 指摘を実装事実と照合し、移動すべき責務、残す責務、最小の変更単位、検証条件を優先順に整理する。
4. レビュー結果をTaskへ記録し、コード変更なしを確認して完了する。

## Verification

- 各指摘を具体的なsymbol・行・依存関係へ結び付ける。
- 既存helperやhookを確認し、重複する抽象化を提案しない。
- `git diff --check`とTask pairの`whub task check`を実行する。

## Review

`TerminalPage`はroute切替、session取得、Operator CRUD、選択・mount・reload、attention、shortcut、Task連携、3ペイン描画を同時に担う。呼出元は`App.tsx`だけで、563行のPageと733行の統合テストへ複数の状態遷移が集中している。

### Priority

1. `TerminalPage.tsx:21,46,197-268`のOperator一覧・起動・停止・pending・errorを、`agentSessions.ts`と同じ具体的なhookへ移す。confirmと起動後の選択はPageに残す。
2. `TerminalPage.tsx:24-30,45-70,87-172,365-405`の選択、fallback、lazy mount維持、reload keyをTerminal固有の`useTerminalSelection`へまとめる。attention既読化は混ぜない。
3. 実施後も必要なら、`TerminalPage.tsx:54-69,139-143,335-361`のTask選択を小さな`TerminalTaskPanel`へ移す。
4. さらに必要なら、`TerminalPage.tsx:270-324`の入力規則を具体的な`useTerminalShortcuts`へ移す。

最初の2項目を一つのlogical changeとして実施し、残りは変更後のPageを再評価する。

### Keep in Page

- `/terminal`と`/terminal/explorer`の表示調停
- 3領域のcomposition
- 明示的選択とvisibility復帰に伴うattention既読化
- collapse状態とlayout・resize signalの接続

`TerminalPage.tsx:328-560`のhidden切替はTerminal接続を維持する。route分割による`TerminalWidget`のunmountは避ける。

### Avoid

- 汎用CRUD、repository、factory、Context、global store、reducer、shortcut registry
- OperatorとWorktreeの無理な統合
- 視覚領域だけを機械的に分割して大量のpropsを渡すcomponent
- Badgeや一行helper単位のファイル分割

### Implementation Verification

- Operator取得中の表示、起動後の選択、指定IDだけの停止を維持する。
- 未選択Terminalを先行mountせず、切替・Explorer遷移でmount済みTerminalを維持する。
- reload対象だけを可視状態で再mountする。
- 既存のTask panel、shortcut、attention契約を維持する。
- focused test、typecheck、build、frontend全テストを実行する。
