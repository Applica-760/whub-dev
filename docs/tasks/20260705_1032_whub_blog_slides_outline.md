# 目的・前提・方針案

- 目的: whub紹介用のブログ構成案と、PKSHA社員面談向けスライド構成案を整理する。
- 前提: ブログは一般公開向け、スライドは面談で自身の課題設定・設計判断・AI活用を紹介する用途。
- 方針案: `slides/blog.md`を参考にするが、構成は尊重しすぎず媒体ごとに最適化する。
- 優先度案: 面談日程が決まっているため、まずスライドから着手する。
