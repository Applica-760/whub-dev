# whub app: ルート単位コード分割

## 目的・前提・方針案

- 目的: 初回JavaScriptを削減し、Viteのチャンク超過警告を解消する。
- 前提: 現在の初回チャンクは556 kB（gzip 173 kB）であり、機能障害はない。
- 方針: ページを`React.lazy`で遅延読込し、依存追加や警告閾値の変更は行わない。

## 計画

### Phase 1: ルート分割
- [ ] Todo・Backlog・Inboxをルート単位で遅延読込し、読み込み中のフォールバックを追加する。
- [ ] `npm run typecheck`・`npm run build`と各ルートの直接表示で分割と既存導線を検証する。
