# ADR-0007: sshfs シングルスレッドモード (-s)

- **Status:** Accepted
- **Date:** 2026-06-21

## Context

sshfs はデフォルトでマルチスレッドで動作し、リソース数分のスレッドが生成される。
過去にマルチスレッド動作でマシンリソースを圧迫した事例があった。

## Decision

`-s` フラグ（シングルスレッドモード）を常時付与する。

## Consequences

- 単一スレッドで処理するためスループットは低下するが、リソース消費を抑制できる
- 多数のリソースを同時マウントしてもスレッド爆発しない
