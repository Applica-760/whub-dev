# ADR-0001: マニフェストを単一YAMLファイルとする

- **Status:** Accepted
- **Date:** 2026-06-19

## Context

workspace-hubが管理する全リソース（ローカルsymlink、SSH接続先、Git情報等）の宣言的定義をどの形式・構成で持つか。

## Decision

単一のYAMLファイルで管理する。

## Rationale

- 管理スコープ（研究・インターン・個人開発・就活・mind）のリソース数は数十件規模
- 1ファイルで全体を一覧でき、実装・AI連携ともにシンプル
- ドメイン分割の利点（編集競合の局所化、スケーラビリティ）は現時点で不要
- 将来分割が必要になった場合も、破壊的変更なしに移行可能

## Consequences

- パース・パス解決が単純になる
- 100件を超える規模になった場合は分割を再検討する
